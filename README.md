# IT Support Portfolio

Hi, I'm Meetkumar Patel. I'm into IT support and systems work, and this repo is where I keep the labs I build to practise it. Each folder is a separate project with its own README, scripts, screenshots and notes on what went wrong along the way.

Everything runs in my own home lab (VMware Workstation VMs, free developer instances and test accounts), so none of it touches real company data.

## Projects

| Project | What it covers | Tools |
|---|---|---|
| [Access Management Lab](access-management-lab/) | Onboarding and offboarding with manager approval, a ticket for every change, and PowerShell scripts that create and disable AD accounts | ServiceNow, Active Directory, PowerShell, Windows Server 2022 |
| [Windows Endpoint & Group Policy Lab](windows-endpoint-lab/) | A Windows 11 workstation joined to the domain, DHCP on the server, Group Policy, a shared drive, tested backups, MFA, asset inventory and a network diagram | Windows 11 Enterprise, Group Policy, DHCP, Windows Server Backup, Bitwarden, draw.io |

I add new projects as I build them.

## Skills across these projects

- **Ticketing / ITSM:** ServiceNow catalog items, approvals, tasks, incidents, knowledge articles
- **Directory services:** Active Directory users, groups, OUs, domain controller setup, domain join
- **Group Policy:** password and lockout policy, mapped drives with item-level targeting, workstation security settings
- **Networking:** DHCP server and scopes, DNS, IP addressing, network diagrams
- **Backup and security:** Windows Server Backup with tested restores, share/NTFS permissions, password manager with MFA
- **Scripting:** PowerShell (bulk user creation, deprovisioning, logging, `-WhatIf` previews)
- **Systems:** Windows Server 2022, DNS, static IP configuration, VMware Workstation
- **Asset management:** PowerShell/CIM hardware inventory
- **Documentation:** runbooks, KB articles, process write-ups, build logs
